# Paper Reproducibility Engine (prototype)

Prototype by Straive's innovation team. It takes published open-access papers, fetches their public data, re-runs the analysis and publishes an honest report card for each claim.

Not affiliated with or endorsed by any publisher. Articles are used under their CC BY licenses; datasets are linked, not mirrored.

- `STATUS.md`: progress
- `CLAIMS_SCHEMA.md`: file contracts
- `scripts/compare.py`: verdict rules, fixed before any reproduction ran
- `papers/<id>/`: claims, code, outputs, logs and report card for each paper
