What the verdicts mean
  • ✓ Reproduced Within the tolerance frozen before analysis; usually the precision printed in the paper.
  • ≈ Partial Outside that tolerance, with the same direction, the same significance when known, and a bounded relative difference.
  • ✗ Not reproduced Computed, but outside the rules for Reproduced or Partial.
  • – Not reproducible Couldn't be computed from the deposited data.

How we checked

Claims and tolerances were frozen before analysis.

  1. ScreenOpen licence, public data, working download
  2. FreezeHeadline numbers and tolerances locked in git
  3. Re-runAuthors' code, or a script from the methods
  4. CompareFixed rules give the verdict
  5. AuditA second agent re-runs from scratch
  6. PackageEach number becomes an AI-lab task

Scope and limitations
  • Papers were picked to be workable, so this is not a reproducibility rate for any journal.
  • Audit categories summarise observations, including possible explanations. They do not establish why every discrepancy occurred.
  • Not verifiable from git: that reproducers logged assumptions before seeing results. The claims freeze is verifiable.
