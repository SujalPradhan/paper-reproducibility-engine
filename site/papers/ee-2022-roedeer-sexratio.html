What the audit found

The birth sex-ratio point estimate reproduces, but its confidence interval does not. The paper prints conflicting sample sizes; temperature estimates depend on scaling the paper leaves unclear. An extra row in the deposit is a possible explanation for the prenatal discrepancy, not an established cause.

What the paper says to do
  1. Read Sex_BW.csv (sep=';', CRLF). Columns: Year (birth year t), Sex ('f'/'m'/'NA'), Hasl (m a.s.l., may be 'NA').
  2. Drop rows with Sex == 'NA'. The paper's period is 1972–2019, so drop Year < 1972 (file spans 1966–2019). Record the resulting N for C1. Whether rows with Hasl == 'NA' are kept for the binomial test is unspecified: report N both with and without Hasl-NA rows.
  3. C2: n_female = count(Sex=='f'), n = count(Sex in {f,m}); pf = n_female/n; 95% CI from exact binomial test (R binom.test(n_female, n), Clopper-Pearson). Round to 2 decimals.
  4. Read Temp_Data_comma_sep.csv (sep=';', dec=','). Jahr = calendar year; Temp_BW_<Mon> = monthly mean temperature (°C); NDS_BW_<Mon> = monthly precipitation.
  5. For each fawn with birth year t: T_OctFeb = mean(Temp_BW_Oct, Temp_BW_Nov, Temp_BW_Dec at Jahr=t−1; Temp_BW_Jan, Temp_BW_Feb at Jahr=t). P_Sep = NDS_BW_Sep at Jahr=t−1.
  6. Apply lapse-rate correction (Equation 3) per fawn: T_cor = T_OctFeb − 0.65 * Hasl/100. Requires non-NA Hasl, so drop Hasl-NA rows for the GLM.
  7. Response y = 1 if Sex=='f', 0 if 'm' (paper: 0 – male, 1 – female).
  8. C5/C6: fit glm(y ~ P_Sep + I(P_Sep^2) + T_cor + I(T_cor^2), family = binomial(link='logit')). Extract the estimate, SE and Wald p for the T_cor and T_cor^2 terms; compare with Table 1 (intercept −0.855 (0.068); P_Sep 0.003 (0.002) p=.11; P_Sep^2 0 (0) p=.13). Sensitivity check: uncorrected T_OctFeb.
  9. climwin window search (Equation 1 / Appendix S7–S8) is NOT reproduced; the paper's selected windows (Temp Oct(t−1)–Feb(t), Precip Sep(t−1)) are taken as given.
  10. Read Metafor_roe_sex.csv (sep=';', dec=',', encoding latin1). Columns: N, N_female, 'Sex ratio' (P=prenatal, S=secondary), d, d_se, Proportion females, Low_95, High_95, North, Eeast.
  11. Use provided d and d_se (paper: 'calculated using data with two decimal places'). Optional check: d = ln(pf/(1−pf))/(pi/sqrt(3)) from Proportion females.
  12. C3: metafor::rma(yi=d, sei=d_se, data=subset(Sex ratio=='P'), method='REML') (random effects, data-set level; default estimator assumed). Report the estimate and 95% CI.
  13. C4: same as C3 on subset(Sex ratio=='S').
  14. Secondary (not a frozen claim): fixed model at reference level (method='FE') after aggregating data sets by reference (Author+Pub_Year): reported −0.05 [−0.07, −0.02] (P) and −0.04 [−0.06, −0.03] (S); I^2 = 11.4% (P) and 0.16% (S).
What the paper leaves unclear
  • Baden-Württemberg sample size is inconsistent: 12,437 (Abstract, Methods, Table 1 caption, Figure 1 caption) vs 12,473 (Table 2 ref 47, Table 3 ID 90) vs 12475 (N in the Hagen row of the deposited Metafor_roe_sex.csv). Sex_BW.csv has 17,260 rows including Sex=='NA' and years 1966–1971 outside the stated 1972–2019 period, so the exclusion rules that yield either N are not stated.
  • Table 1: Temperature (Oct–Feb) estimate 0.019 with SE 0.084 is inconsistent with p = .03 (Wald z ≈ 0.23 → p ≈ 0.82). Either the SE or the p is misprinted (e.g. SE 0.0084?). The SEs of the squared terms and the precipitation^2 estimate are printed as '0' (3-decimal rounding), so their values cannot be checked meaningfully.
  • Lapse-rate correction (Equation 3) subtracts 0.65 °C per 100 m from the state-wide mean temperature, with no reference elevation. It is unclear whether it was applied to the window mean or to the monthly values, and how fawns with Hasl == NA were handled. It is also unclear whether precipitation was centred/scaled.
  • The paper says GLMs were run with lme4, but Equation 2 has no random effects; lme4 cannot fit a plain GLM (glmer requires a random term). Possible unreported random effect (e.g. year or height class), or base-R glm was actually used.
  • The four height classes (<250, 250–500, 500–750, ≥750 m) were used in climwin; it is unclear whether height class enters the final Equation 2 model.
  • Meta-analysis: the text says 51 data sets (36 prenatal + 15 secondary), but Metafor_roe_sex.csv has 52 rows (37 P + 15 S). Several N values differ between the CSV and Table 2 (e.g. Stubbe et al. CSV 166 vs Table 2 116; Majzinger CSV 53 vs Table 2 73; Ellenberg CSV 147 vs Table 2 193 but Table 3 147).
  • The τ² estimator for the random-effects model is not stated (metafor default REML assumed). How data sets were aggregated to 'references' for the fixed model is not stated.
  • The mortality-corrected sex for 3280 re-encountered fawns (97 corrections): it is not stated whether Sex_BW.csv already holds the corrected sex. There is no age column, so the <3-day and <7-day subsets (Figures S5–S6) cannot be reproduced.
  • The paper reports an exact binomial test for Baden-Württemberg but gives no p-value, only the proportion and CI (2 decimals).
