# Addendum

Clarifications drawn from the paper (frozen before reproduction):

- Load data/EI_and_Happiness_raw_Data_with_coding.sav (SPSS; e.g. pyreadstat or R haven). Expect 405 rows x 90 columns with no missing values. The paper excluded 13 incomplete questionnaires before deposit, so no further exclusions are needed.
- Sanity checks against Table 1 (not graded claims): n = 405; Gender 1=Male 208, 2=Female 197; AGE mean 24.2 (SD 1.82); Personality_assessment 1=Introvert 233, 2=Extrovert 172; Living_stress_score mean 5.82 (SD 2.31); self_physical_examination mean 81.8 (SD 16.6); EI_score_total mean 34.6 (SD 6.16); happiness mean total score/29 = 3.78 (SD 0.85).
- Outcome: happiness = total_Happiness_score / 29 (Oxford Happiness Questionnaire, range 1-6; the 12 reverse-scored items are already reversed in the R_H* columns). Adj_total_happiness is the same quantity as deposited. Under a log-link gamma GLM, rescaling y changes only the intercept, so Exp(B) is the same whether total_Happiness_score or total/29 is used. Prefer total_Happiness_score/29 computed at full precision.
- Categorical predictors as factors, with the reference levels given in Table 2: Gender (ref 1=Male); Marital_status (ref 1=Single; levels Married, In a relationship); Clinical_Grade (ref 1=One-year stager; Two-year stager, Intern); University (ref 1=Shiraz; Fasa, Jahrom); Living (ref 1=Dormitory; Family residence, Independent residence); Ethnicity (ref 1=Persian); Job (ref 0=no part-time job); Salary (ref 1=Without income); Siblings (ref 1='1-2'); Outstanding_students (ref 0=not top student); Parrents_living_status (ref 1=Joint living parents; Separated, Deceased a parent; label 4 has no observations); Personality_assessment (ref 1=Introvert); Thinking_immigration (ref 0); exhustion_to_work (ref 0, emotional exhaustion); No_feeling_at_work (ref 0, depersonalization); Happiness_compared_before_pandemy (ref 1='Get worsed').
- Continuous predictors: AGE (years), Living_stress_score (stress VAS, observed 1-10), self_physical_examination (somatic health VAS, observed 10-100), and the five EI domain scores Appraisal_own_emotions, Regulation_of_own_emotion, Appraisial_of_others_emotion, Regulation_others_emotion, Utilization_of_emotions (each 2-10). EI_score_total is NOT entered, because it is collinear with the domains.
- Primary analysis (pre-registered interpretation): ONE multivariable gamma GLM with log link containing all 16 categorical and 8 continuous predictors listed in Table 2. Stata 17: glm happiness i.Gender i.Marital_status ... AGE Living_stress_score self_physical_examination <5 EI domains>, family(gamma) link(log) eform. R equivalent: glm(happiness ~ ..., family = Gamma(link = 'log')).
- Report for each claim exp(b), the delta-method SE of exp(b) (= exp(b) * se(b), as Stata eform prints), the Wald p-value, and the 95% CI exp(b +/- 1.96 se(b)). Stata glm uses z (normal) p-values and CIs with the Pearson-chi2-based dispersion. R's summary.glm uses t, so compute normal-based p and CI to match Stata.
- Variables in the deposit but NOT in Table 2, which are therefore not in the model: Enterance_year, Semester, Tuition_status, balance_between_salary_and_costs, High_School, Fathers_education, Mothers_Education, Fathers_job, Mothers_job, previous_participitation.
- Sensitivity (diagnostic only, not graded): if the multivariable model fails to match, fit separate univariable gamma GLMs per variable (the Table 2 footnote mentions 'each category regression analysis'), and also report a model with only the EI domains plus the significant covariates.
- Second stage (not graded): GBRT (R 4.1.1, package unspecified, probably gbm) of happiness on the variables significant in stage 1, with relative influence plotted in Figure 3. Hyperparameters and seed are not reported, so only the ranking (Regulation of own emotions first, Utilization of emotions second) could be compared qualitatively.
