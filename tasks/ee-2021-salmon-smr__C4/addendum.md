# Addendum

Clarifications drawn from the paper (frozen before reproduction):

- Run order per author README: 1-prep-functions.R, 2-prep-data.R, then 4-models-*.R. 3-prep-plots.R and the plotting parts that use axomatic::axis_x/axis_y, extrafont and loadfonts(device='win') are not needed for any claim. Working directory = folder with the data files. Author sets options(na.action='na.fail').
- Load data-Ash2021-sampled-fish.xlsx sheet 1 with readxl::read_xlsx (165 rows). Parse `date` with lubridate::dmy (format d.mm.yy). Compute condition = (weight / (length_standard/10)^3) * 100. Note that this uses length in cm despite the paper saying mm.
- Temperature: read data-Ash2021-temp-loggers-small-tanks-Dec2020.txt. Parse dateTime with ymd_hms and turn tank to numeric (the author code recodes '1_10' and then calls numextract, so the '10_0' label becomes 10). Keep dateTime < 2020-07-15 and tank in 1:14. Average temp across tanks per timestamp (tb_tempLog_one). For each fish, avgTemp = mean of tb_tempLog_one$temp with dateTime strictly between (date - 5 days) and (date - 2 days).
- Join individual data to data-Ash2021-genotypes.txt by ID_sample, which adds sex (female/male) and geno_vgll3 (EE/LL). The author code also joins tank densities and tank mean temps by family = tank, but these are unused in the models.
- Load data-Ash2021-respirometry.txt (read.delim, 7311 rows). Rename Ind -> ID_fish, Mass -> mass, Chamber.No -> chamber_ch, Volume -> volume_ch, Date.Time -> dateTime (ymd_hms on strings like '(2020-Jul-03 16:25:32)'). Left-join individual data by ID_fish.
- SMR per fish: group by ID_fish, mass, volume_ch, chamber_ch, and take SMR = calcSMR(MR.abs)$mlnd. This is the mean of the lowest normal distribution from mclust::Mclust(Y, G=1:4) on all retained phases of that fish, following Chabot et al. 2016. Use the author's calcSMR verbatim, including its `length(time)` quirk (see ambiguities). No extra removal of the acclimation period.
- Exclusions: keep fish with use > 0.5 in the xlsx. This should leave N = 150 (76 LL, 74 EE; 69 males, 81 females; 14 families; 10 batches). Convert family, chamber, geno_vgll3 and sex to factors. The reference levels come out as EE and female (alphabetical), matching the 'vgll3 (LL)' and 'Sex (male)' rows in Table A1.
- Model 1 (C1–C4): lmerTest::lmer(log10(SMR) ~ log10(weight) + geno_vgll3*sex + avgTemp + (1|family) + (1|batch), data = tb_smr), REML. Body mass is the post-respirometry `weight` from the xlsx, not respirometry `Mass`. Report the fixed-effect estimates, Wald or profile 95% CIs from confint() (the author uses the default confint, which is profile for merMod), type III anova (Satterthwaite) for p/F, and sigma() as the residual SD.
- Model 2 (C5): lmerTest::lmer(condition ~ geno_vgll3*sex + (1|batch) + (1|family), data = tb_smr), REML, with confint() and anova(type=3).
- Alternative models for AIC and cross-validation (context only, not scored): rate1.5 (no interaction), rate2 (sex only), rate3 (simple: log10(weight) + avgTemp). Compare them with AIC() and with cvms::cross_validate using 2 folds (odd vs even batch), natural-log variables, and only (1|family) as the random effect.
- CV of residuals (context for C4): residual SD converted from log10 to ln scale (× ln 10) as a percentage, per Garland 1984.
- Power analysis (C6): run script-Ash2021-powerAnalysis.R. For n = 150, simulate y = 1 + 0.83*b0 + c_b1*b1 + c_b12*b1*b2 + N(0, 0.027), with b0 ~ N(1.07, 0.3) (body mass, not logged), b1 = genotype (half 0, half 1) and b2 = sex alternating 0/1. Fit lm(y ~ b0 + b1*b2) and test the b1 coefficient p < 0.05. Use c_b1 = log10(1 + seq(1,5,0.25)/100), with c_b12 = -c_b1 as in the code, and 10000 simulations per grid point. The minimum detectable effect is the smallest grid value with power >= 0.8. multidplyr parallelisation can be dropped. Set a seed and report it.
