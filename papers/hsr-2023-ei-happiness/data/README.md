# Data for hsr-2023-ei-happiness

Paper: Hatamnejad et al. (2023), "Emotional intelligence and happiness in clinical medical students: a cross-sectional multicenter study", Health Science Reports 6:e1745, doi:10.1002/hsr2.1745 (PMC10709659).

Dataset: Figshare, doi:10.6084/m9.figshare.23291780 (v1), "EI and Happiness raw Data with coding.sav". License: **CC BY 4.0** (per the Figshare API `license` field).

The file was renamed locally (spaces replaced with underscores). Its MD5 `3b96b17701cef8b656e5d754be268e13` matches Figshare's `computed_md5`.

Structure: an SPSS .sav file with 405 rows and 90 variables and no missing values. Variables include demographics (AGE, Gender, Marital_status, Clinical_Grade, University, Living, Ethnicity, Job, Salary, Siblings, Outstanding_students, Parrents_living_status, ...), self-perception items (Living_stress_score, self_physical_examination, Personality_assessment, Thinking_immigration, exhustion_to_work, No_feeling_at_work, Happiness_compared_before_pandemy), BEIS-10 items EI1–EI10 with five domain scores and EI_score_total, and Oxford Happiness items H1–H29 (the 12 reverse-scored items are already reversed and carry an `R_` prefix). It also has the happiness domain totals, the "Adj_" per-item means, total_Happiness_score (29–174) and Adj_total_happiness (1–6).

Author code: none was deposited.
